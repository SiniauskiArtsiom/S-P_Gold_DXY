# Анализ взаимосвязи S&P 500, Золота и Индекса доллара (DXY) с помощью VAR и DCC-GARCH

## Описание проекта
Данный проект посвящен анализу и прогнозированию динамики трех ключевых макроэкономических активов: фондового индекса **S&P 500**, **Золота** (Gold) и **Индекса доллара США** (DXY). 

Проект выполнен в рамках классического эконометрического подхода, который широко используется в **банковском риск-менеджменте** для оценки рыночного риска (Value-at-Risk, VaR), стресс-тестирования портфелей и анализа эффекта «заражения» (contagion) во время кризисов.

## Задачи проекта
1. Сбор и предобработка исторических данных за 5 лет.
2. Проверка рядов на стационарность (ADF-тест) и переход к логарифмическим доходностям.
3. Построение модели векторной авторегрессии (VAR) для моделирования многомерного среднего.
4. Диагностика остатков VAR (тесты на автокорреляцию и ARCH-эффекты).
5. Моделирование многомерной волатильности с помощью DCC-GARCH (реализация кастомной функции правдоподобия).
6. Прогнозирование доходностей и оценка качества моделей (RMSE, MAE) с построением адаптивных доверительных интервалов.

## Используемые данные
*   **Источник:** Yahoo Finance (библиотека `yfinance`).
*   **Период:** Последние 5 лет (дневные данные).
*   **Активы:** 
    *   `^GSPC` (S&P 500) — фондовый рынок США.
    *   `GC=F` (Gold) — фьючерс на золото.
    *   `DX-Y.NYB` (USD_Index) — Индекс доллара США (DXY).

## Используемый стек технологий
*   **Python 3.12**
*   **Работа с данными:** `pandas`, `numpy`, `yfinance`
*   **Эконометрика и статистика:** `statsmodels` (VAR, ADF, LM-тесты), `arch` (GARCH)
*   **Оптимизация:** `scipy` (для реализации DCC-GARCH)
*   **Визуализация:** `matplotlib`, `seaborn`

## Методология и ключевые результаты

### 1. Предобработка и стационарность
Исходные ряды цен нестационарны (подтверждено ADF-тестом, p-value > 0.05). Для приведения рядов к стационарному виду рассчитаны **логарифмические доходности**. Повторный ADF-тест подтвердил стационарность полученных рядов (p-value < 0.05).

### 2. Модель VAR (Векторная авторегрессия)
*   По информационным критериям (AIC, FPE) выбран оптимальный лаг **p=1**.
*   **Тест на ARCH-эффекты:** показал p-value = 0.00000 для всех активов, что доказало необходимость моделирования волатильности.
*   **Тест Грейнджера:** не выявил статистически значимой причинно-следственной связи на дневных данных при лаге 1 (что нормально для высоколиквидных рынков).

### 3. Моделирование волатильности (MGARCH)
*   Оценены одномерные **GARCH(1,1)** модели для остатков каждого актива. Выявлена высокая персистентность волатильности (сумма \(\alpha + \beta\) близка к 1), особенно для Золота и Индекса доллара.
*   Реализован **DCC-GARCH (Dynamic Conditional Correlation)** с использованием кастомной функции максимального правдоподобия.
*   Построены графики **динамических корреляций**. Выявлено, что в моменты системных шоков корреляции меняются (эффект contagion), что критически важно для диверсификации портфеля.

### 4. Прогнозирование
*   Выборка разделена на Train (80%) и Test (20%).
*   Построен совместный точечный и интервальный прогноз доходностей.
*   Построены **адаптивные 95% доверительные интервалы** (Mean ± 1.96 * Volatility). В периоды турбулентности "коридор неопределенности" расширяется, корректно отражая рост рисков.
*   Метрики качества на тесте: MAE и RMSE (наименьшие ошибки у USD_Index, наибольшие — у Золота).
